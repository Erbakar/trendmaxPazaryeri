Ön Koşullar

Entegrasyona başlamadan önce sisteminizin, sunucunuzun ve OzyConnect hesabınızın aşağıdaki koşulları sağladığını doğrulayın. Bu adım, sonraki aşamalarda yaşanacak sorunların büyük çoğunluğunu baştan ortadan kaldırır.

İstemci (Müşteri) Tarafı Gereksinimleri

Sizin (müşterimiz) tarafınızda API çağrılarını gerçekleştirecek sunucu ya da uygulamanın aşağıdakileri desteklemesi gerekir:

  • HTTPS üzerinden dış bağlantı kurabilme (giden 443/TCP portu açık olmalı).
  • HMAC-SHA256 desteği olan bir programlama dili (PHP 7.4+, Node.js 14+, Python 3.8+, .NET 6+, Java 11+ vb.).
  • JSON serileştirme / deserileştirme kütüphanesi.
  • Sunucu saatinin NTP ile senkron tutulması (timestamp farkı ±5 dakikayı geçemez).
  • API Key ve Secret değerlerini güvenli bir şekilde saklayabileceğiniz bir ortam (ENV değişkeni, secret manager vs.).

Önemli. Sunucunuzun saati yanlışsa, imzalar 401 Unauthorized hatası verebilir. Üretim ortamlarınızda NTP zorunludur.

Ağ ve Bağlantı

Giden Bağlantı

OzyConnect API'sine yapılacak her çağrı, müşteri sunucunuzdan bizim altyapımıza HTTPS (TCP/443) üzerinden gerçekleşir. Firewall veya proxy cihazlarınızın bu trafiği engellemediğinden emin olun.

IP Whitelist (Opsiyonel)

Güvenlik seviyenizi arttırmak için API anahtarınıza IP kısıtlaması tanımlayabilirsiniz. Sadece belirttiğiniz IP adreslerinden gelen istekler kabul edilir.

bash# Sunucunuzun çıkış IP'sini öğrenmek için:
curl -s https://api.ipify.org
# Örn: 185.xxx.xxx.xxx

İpucu. Üretim sunucunuz ve test sunucunuz farklı IP'lerde ise iki adresi de whitelist'e eklemeyi unutmayın. Yük dengeleyici / NAT arkasında iseniz çıkış IP'lerinin tamamı eklenmelidir.

OzyConnect Hesap Gereksinimleri

Aşağıdaki bilgiler entegrasyondan önce tarafınıza iletilmiş olmalıdır. Eğer eksik veya bilmediğiniz bir bilgi varsa Destek sayfamızdan iletişime geçin.

Bilgi Durum Açıklama
OzyConnect Panel URL'i Zorunlu Örn: https://panel.musteri.com/ozyconnect
API Key Zorunlu Panel üzerinden Ayarlar → API Tokens ekranından üretilir.
API Secret Zorunlu Sadece oluşturma anında bir kez gösterilir. Güvenli bir yerde saklayın.
Permission Scope Zorunlu Örn: products:*, orders:read. İhtiyacınıza göre belirlenir.
IP Whitelist Önerilir Üretimde mutlaka etkinleştirin.
Rate Limit Opsiyonel Varsayılan 10 req/sn. Daha yüksek limit için talepte bulunun.
Cron Token Opsiyonel Sadece sunucu taraflı planlı işler için gereklidir.

Kontrol Listesi

Bir sonraki adıma geçmeden önce aşağıdaki maddelerin tamamının karşılandığını doğrulayın:

  • Sunucumun çıkış IP'sini biliyorum ve OzyConnect tarafına bildirdim.
  • Panel URL'im, API Key ve API Secret bilgilerim elimde.
  • Kodlayacağım dilde HMAC-SHA256 desteği mevcut.
  • Sunucu saatim NTP ile senkron (timedatectl veya w32tm /query /status).
  • Secret değerini ENV dosyasına yazacağım, asla kaynak kodla birlikte commit'lemeyeceğim.
  • Rate limit değerini biliyorum ve uygulamam buna göre ölçeklenecek.

Hazırsınız! Bu listeyi doğruladıysanız sonraki adıma — Kimlik Doğrulama — geçebilirsiniz.
