Bu Entegrasyon Size Ne Sağlar?

OzyConnect REST API, e-ticaret operasyonlarınızı tek bir yerden yönetmek için geliştirilmiştir. Aşağıdaki yetenekler entegrasyonunuzda doğrudan kullanılabilir:

  • ✓
    Ürün Yönetimi — Listeleme, oluşturma, güncelleme ve pazaryerine senkronizasyon.
  • ✓
    Sipariş Akışı — Tüm pazaryerlerinden gelen siparişleri tek bir API üzerinden yönetin.
  • ✓
    Stok & Fiyat — Gerçek zamanlı stok/fiyat güncellemeleri ve toplu işlem desteği.
  • ✓
    Kategori & Marka — Ağaç yapısı, pazaryeri eşleştirmesi, otomatik senkronizasyon.
  • ✓
    Güvenli Erişim — HMAC-SHA256 imzalı istekler, IP whitelist, rate limit.
  • ✓
    Otomasyon — Cron endpointleri ile planlanmış görev desteği.
