Sistem Gereksinimleri

Kuruluma başlamadan önce aşağıdaki servislerin ve izinlerin hazır olması gerekir. Installer ilk adımda bunların çoğunu otomatik kontrol eder.

Çalışma Ortamı

PHP 8.2 veya üzeri, Apache, mod_rewrite ve UTF-8 uyumlu MySQL/MariaDB veritabanı.

PHP Eklentileri

pdo_mysql, curl, openssl, mbstring, json ve fileinfo.

Yazma İzinleri

storage, public/uploads ve installer sırasında oluşturulan .env dosyası yazılabilir olmalı.

Başlık Önerilen Değer Not
PHP 8.2+ Composer gereksinimi php >=8.2 olarak tanımlıdır.
Veritabanı MySQL 5.7+ / MariaDB 10.4+ Karakter seti utf8mb4, karşılaştırma utf8mb4_unicode_ci kullanılmalıdır.
Web Sunucusu Apache + mod_rewrite Kök dizindeki .htaccess statik dosya, güvenlik ve rota yönlendirmelerini yönetir.
Dosya İzinleri Yazılabilir storage klasörleri storage/logs, storage/cache, storage/feeds, storage/invoices, storage/backups.
URL http://localhost veya alan adınız Installer bu değeri APP_URL olarak .env dosyasına yazar.
Güvenlik HTTPS, güçlü admin şifresi, kapalı debug Canlı ortamda APP_ENV=production ve APP_DEBUG=false kullanılmalıdır.

Adım Adım Kurulum

Önerilen yöntem installer sihirbazıdır. Manuel müdahale sadece sunucu izinleri veya veritabanı erişimi kısıtlıysa gerekir.

Standart Installer Akışı

En hızlı ve düşük riskli kurulum yolu.

Önerilen
  1. 1

    Dosyaları sunucuya yükleyin

    Proje dosyalarını web köküne (public_html veya www) yükleyin. vendor klasörü yoksa composer bağımlılıklarını kurun.

    composer install --no-dev --optimize-autoloader
  2. 2

    Veritabanı bilgilerini hazırlayın

    Boş bir veritabanı adı, kullanıcı adı ve şifre belirleyin. Installer gerekirse veritabanını oluşturmayı dener.

    DB_HOST DB_PORT DB_NAME DB_USER
  3. 3

    installer.php dosyasını açın

    Tarayıcıdan /installer.php adresine gidin. Gereksinimler yeşilse veritabanı adımına geçin.

  4. 4

    Admin hesabını oluşturun

    Geçerli e-posta ve en az 8 karakterli güçlü şifre girin. Kurulum sonunda .env ve installer_done.lock oluşturulur.

  5. 5

    Panele giriş yapın

    Kurulum tamamlandığında /login adresinden giriş yapıp ilk ayarları tamamlayın.

.env dosyası

Installer otomatik üretir. Canlı ortamda APP_DEBUG=false, doğru APP_URL ve güçlü ENCRYPTION_KEY kullanılmalıdır.

Schema ve seed

database/schema.sql ve database/seed.sql kurulum sırasında veritabanına uygulanır.

Rota kontrolü

.htaccess kök istekleri public/index.php dosyasına yönlendirir. mod_rewrite kapalıysa panel açılmaz.

Tekrar kurulum koruması

installer_done.lock oluştuğunda installer erişimi engellenir. Bu dosyayı canlıda koruyun.

Kurulumdan önce yedek alın.

Mevcut bir kurulum üzerine işlem yapıyorsanız .env, storage, public/uploads ve veritabanını mutlaka yedekleyin.

İlk Yapılandırma ve Yayına Alma

Panel açıldıktan sonra asıl operasyonel değer bu kontrollerle başlar: pazaryeri bağlantıları, cron işleri, fatura ayarları ve güvenlik.

Yayın Öncesi Kontrol Listesi

Canlı kullanım öncesinde tamamlanmalı.

8 kontrol
  • Admin bilgileri: Varsayılan veya zayıf şifre bırakılmadı.
  • APP_URL: Alan adı veya yerel yol doğru tanımlandı.
  • Debug: Canlı ortamda hata çıktısı kapatıldı.
  • Pazaryerleri: API anahtarları girildi ve bağlantı test edildi.
  • Fatura: GİB/e-Arşiv ayarları ve seri başlangıcı kontrol edildi.
  • Yedekleme: Otomatik veya manuel yedek akışı doğrulandı.
  • Loglar: storage/logs yazılabilir ve erişime kapalı.
  • HTTPS: Canlı domain SSL ile çalışıyor.

Cron Örnekleri

Panel otomasyonları için planlanmış görevler.

CLI

Sunucu cron paneline aşağıdaki komutları ihtiyaca göre ekleyin. Yolları kendi kurulum dizininize göre güncelleyin.

php /home/kullanici/public_html/cron/sync_orders.php
php /home/kullanici/public_html/cron/sync_stock.php
php /home/kullanici/public_html/cron/generate_backups.php
API kullanacaksanız token oluşturun.

Panelde Ayarlar / API Tokenları bölümünden erişim anahtarı oluşturun. Entegrasyon detayları için API kurulum rehberini kullanabilirsiniz.

Sorun Giderme

Kurulum sırasında en sık görülen durumlar ve hızlı kontrol noktaları.

Belirti Olası Neden Çözüm
Beyaz sayfa veya 500 hatası PHP eklentisi eksik, veritabanı bağlantısı hatalı veya log dizini yazılamıyor. storage/logs içindeki son logu kontrol edin, .env DB bilgilerini doğrulayın.
404 veya rota çalışmıyor Apache mod_rewrite kapalı ya da .htaccess okunmuyor. Apache yapılandırmasında AllowOverride All ve mod_rewrite aktif olmalı.
Installer devam etmiyor Gereksinim kontrolünde eksik PHP eklentisi veya yazma izni var. Eksik satırı giderin, sayfayı yenileyin ve gereksinim kontrolünü tekrar çalıştırın.
Veritabanı bağlantı hatası Kullanıcı yetkisi, host, port veya veritabanı adı yanlış. Kullanıcıya CREATE/ALTER/INSERT/UPDATE yetkisi verin veya mevcut DB adını girin.
Logo, CSS veya görseller gelmiyor Statik dosya yolu veya web kök dizini yanlış konumlanmış olabilir. Kurulum klasörünün web kökünde olduğundan ve public/assets dosyalarının bulunduğundan emin olun.
Canlı ortamda hassas dosyaları paylaşmayın.

.env, veritabanı yedekleri, log dosyaları ve API anahtarları destek talebinde açık şekilde gönderilmemelidir. Gerekirse değerleri maskeleyin.
