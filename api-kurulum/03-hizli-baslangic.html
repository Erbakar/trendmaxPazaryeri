Hızlı Başlangıç

5 dakikada ilk API isteğinizi göndermek ve canlı yanıtı görmek için ihtiyacınız olan her şey burada. Aşağıdaki adımları sırayla takip etmeniz yeterli.

5 Dakikalık Entegrasyon Planı

  1. Taban URL'i Yapılandırın

    Panelinize özel URL'i değişken olarak tanımlayın.

    envOZY_BASE_URL=https://panel.musteri.com
OZY_API_KEY=oxy_abc123def456
OZY_API_SECRET=your_api_secret_here

  2. Bağlantıyı Test Edin (Ping)

    Kimlik doğrulamaya gerek duymayan /api/v1/ping endpoint'i ile iletişimi doğrulayın.

    bashcurl -s "$OZY_BASE_URL/api/v1/ping"

# Beklenen yanıt:
# {"status":"ok","version":"1.0.0","time":"2026-04-28T09:21:14Z"}

  3. İlk Kimlik Doğrulamalı İsteği Gönderin

    GET /api/v1/products?page=1&per_page=5 çağrısı ile ilk ürünleri alın.

    bash# Bu örnek önceden üretilmiş bir imza ile çalışır.
# Gerçek projede aşağıdaki Authorization'ı dinamik üretmelisiniz.
curl -s "$OZY_BASE_URL/api/v1/products?page=1&per_page=5" \
     -H "Authorization: Bearer $OZY_API_KEY:$SIGNATURE:$TIMESTAMP:$NONCE" \
     -H "Content-Type: application/json"

  4. Yanıtı Doğrulayın

    Başarılı yanıt aşağıdaki yapıda gelir. Eğer 401 alıyorsanız Kimlik Doğrulama adımını, 403 alıyorsanız token'ınızın yetki kapsamını kontrol edin.

    json{
  "data": [
    {
      "id": 1,
      "sku": "PROD001",
      "name": "Ürün Adı",
      "price": 99.99,
      "stock": 100,
      "status": "published"
    }
  ],
  "pagination": {
    "total": 250,
    "page": 1,
    "per_page": 5
  }
}

  5. Entegrasyonunuzu Canlıya Alın

    Staging ortamında testleri tamamladıktan sonra üretim ortamı için yeni bir API Key talep edin, IP whitelist tanımlayın ve trafiği kademeli olarak yönlendirin.

Uçtan Uca Çalışan Örnek (PHP)

Aşağıdaki tek dosyalık örnek, tüm süreci tek bir yerde gösterir: imza üretimi, HTTP isteği, yanıt işleme ve hata yönetimi.

ozyconnect-client.php<?php
declare(strict_types=1);

class OzyConnectClient
{
    private string $baseUrl;
    private string $apiKey;
    private string $apiSecret;

    public function __construct(string $baseUrl, string $apiKey, string $apiSecret)
    {
        $this->baseUrl   = rtrim($baseUrl, '/');
        $this->apiKey    = $apiKey;
        $this->apiSecret = $apiSecret;
    }

    public function request(string $method, string $endpoint, array $query = [], array $body = []): array
    {
        $method    = strtoupper($method);
        $timestamp = time();
        $nonce     = bin2hex(random_bytes(8));

        $message   = "{$method}\n{$endpoint}\n{$timestamp}\n{$nonce}";
        $signature = hash_hmac('sha256', $message, $this->apiSecret);

        $url = $this->baseUrl . $endpoint;
        if ($query) {
            $url .= '?' . http_build_query($query);
        }

        $ch = curl_init($url);
        curl_setopt_array($ch, [
            CURLOPT_CUSTOMREQUEST  => $method,
            CURLOPT_RETURNTRANSFER => true,
            CURLOPT_TIMEOUT        => 30,
            CURLOPT_HTTPHEADER     => [
                "Authorization: Bearer {$this->apiKey}:{$signature}:{$timestamp}:{$nonce}",
                'Content-Type: application/json',
                'Accept: application/json',
            ],
            CURLOPT_POSTFIELDS     => $body ? json_encode($body, JSON_UNESCAPED_UNICODE) : null,
        ]);

        $raw    = curl_exec($ch);
        $status = curl_getinfo($ch, CURLINFO_HTTP_CODE);
        $err    = curl_error($ch);
        curl_close($ch);

        if ($raw === false) {
            throw new RuntimeException("HTTP hatası: {$err}");
        }

        $data = json_decode($raw, true) ?? [];

        if ($status >= 400) {
            throw new RuntimeException("API hatası {$status}: " . ($data['message'] ?? 'Bilinmeyen hata'));
        }

        return $data;
    }
}

// --- Kullanım ---
$client = new OzyConnectClient(
    getenv('OZY_BASE_URL'),
    getenv('OZY_API_KEY'),
    getenv('OZY_API_SECRET')
);

try {
    $products = $client->request('GET', '/api/v1/products', [
        'page'     => 1,
        'per_page' => 20,
    ]);
    foreach ($products['data'] as $p) {
        echo "#{$p['id']} {$p['sku']} — {$p['name']} ({$p['price']} TL)\n";
    }
} catch (RuntimeException $e) {
    fwrite(STDERR, $e->getMessage() . "\n");
    exit(1);
}

Tebrikler! Bu örneği çalıştırabildiyseniz entegrasyonun temeli hazır demektir. Üretim öncesi mutlaka Hata Yönetimi sayfasını okuyun.

Sık Yapılan Hatalar

Endpoint'e query string ekleyerek imzalamak. İmzalanan mesajda endpoint değeri sorgu parametreleri hariç olmalıdır. Aksi halde sunucu farklı bir imza hesaplar ve 401 alırsınız.

Timestamp'i milisaniye olarak göndermek. Unix timestamp saniye cinsinden olmalıdır. time() veya Math.floor(Date.now() / 1000) kullanın.

Boş POST body'si göndermek. Content-Type: application/json başlığı ile birlikte boş body gönderilirse bazı istemciler {} yerine hiçbir şey yollamaz. Bu sorun yaşıyorsanız açıkça {} yollayın.

Aynı nonce'u tekrar kullanmak. Her çağrı için yeni bir rasgele nonce üretin. Aynı nonce + timestamp kombinasyonu tekrar eden istek olarak algılanabilir.
