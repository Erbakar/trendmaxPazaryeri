SSS & Destek

Sıkça sorulan sorular ve entegrasyon sürecinde size yardımcı olacak iletişim kanalları. Sorununuz aşağıda listelenmemişse lütfen bizimle iletişime geçin.

Sıkça Sorulan Sorular

API Secret değerimi kaybettim, ne yapmalıyım?

Secret değerler güvenlik nedeniyle sadece oluşturma anında bir kez gösterilir ve hiçbir yerde saklanmaz. Panel üzerinden mevcut token'ı silip yenisini oluşturmanız gerekir. Eski token anında geçersiz hale gelir.

Staging / test ortamı var mı?

Evet. Üretim ortamından bağımsız bir test panel ve API Key çifti talep edebilirsiniz. Test ortamında yapılan işlemler gerçek pazaryerlerine gönderilmez, sadece mock yanıtlar üretilir.

Rate limit yetersiz geliyor, arttırabilir miyim?

Evet. Gerçek trafik profilinizi (günlük istek sayısı, pik saatler, batch işleri vs.) iletirseniz token bazında limit ayarı yapabiliriz.

API yanıtları ne kadar süre cache'leniyor?

Okuma endpointleri için Cache-Control header'ı döner. Listeleme çağrılarında kısa süreli (30 sn) edge cache kullanılır. Kritik taze veri için Cache-Control: no-cache göndererek cache'i devre dışı bırakabilirsiniz.

Webhook desteği var mı?

Şu anki sürümde webhook yerine cron tabanlı senkronizasyon önerilmektedir. Olay bazlı (order.created, stock.updated vb.) webhook desteği yol haritamızdadır; teklif talebinde bulunabilirsiniz.

Tarih / saat dilimi nasıl yorumlanıyor?

Tüm tarih değerleri UTC ve ISO 8601 formatında (YYYY-MM-DDTHH:MM:SSZ) döner. Kullanıcı arayüzünüzde Europe/Istanbul dilimine dönüştürmeniz gerekir.

Sayfalamada total_pages neden bazen değişiyor?

Veri, işleminiz sırasında değişebilir (yeni ürün eklenmesi gibi). Toplam sayfa, her yanıtta anlık olarak yeniden hesaplanır. Büyük veri tarama işlerinde updated_at filtresi kullanmanızı tavsiye ederiz.

Birden fazla pazaryerini tek istek ile güncelleyebilir miyim?

Hayır. Tek bir OzyConnect çağrısı ile değişiklik yaparsınız; OzyConnect arka planda ilgili tüm pazaryerlerine senkronizasyonu tetikler. Bu sayede yazışma tek bir yerden yönetilir.

Üretimde HTTPS dışında bir şey kullanabilir miyim?

Hayır. Üretim ortamında HTTP trafiği engellenir. Geliştirme yaparken self-signed sertifika ile local HTTPS kurmanızı öneririz.

Token'ı unuttum ama silmek istemiyorum, yenileyebilir miyim?

Evet, panel üzerinden Secret Rotate işlemi ile yeni Secret üretebilirsiniz. API Key değişmez; yalnızca imzalamada kullanılan Secret yenilenir.

Canlıya Alma Kontrol Listesi

Üretim ortamına geçiş öncesi aşağıdaki maddelerin tamamını doğrulayın:

  • Üretim API Key/Secret değerleri staging'den farklı ve güvenli şekilde saklanıyor.
  • IP whitelist üretim IP'lerinizle tanımlandı.
  • Sunucu saati NTP ile senkron.
  • HTTPS sertifikası geçerli ve otomatik yenileme aktif.
  • Retry + exponential backoff uygulandı.
  • Kritik yazma işlemleri Idempotency-Key kullanıyor.
  • Rate limit monitörü kuruldu ve alarm tanımlandı.
  • Hata logları request_id ile birlikte kaydediliyor.
  • Authorization header'ı üretim loglarında maskelenmiş.
  • Staging ortamında tam regresyon testi geçti.

Destek Talebinde Neler Gönderilmeli?

Size daha hızlı yardımcı olabilmemiz için aşağıdaki bilgileri dahil edin:

  • API Key'inizin ilk 6 karakteri (oxy_ab...). Secret'ı asla paylaşmayın.
  • İstek tarih/saati (UTC) ve hedef endpoint.
  • Dönen yanıttaki request_id.
  • Aldığınız HTTP durum kodu ve code alanı.
  • İmza üretiminde kullandığınız örnek mesaj (Secret maskeli).
  • Problem ilk ne zaman ortaya çıktı ve tekrarlanabilir mi?

Örnek destek mesajı. "oxy_ab2f... ile 2026-04-28 10:33 UTC civarı POST /api/v1/orders/ORD123/status çağrısı yaptım, request_id: req_8a1f2c09, 429 alıyorum. Retry-After 12 geldi, sonrasında da RATE_LIMIT_EXCEEDED sürdü. Aynı token ile /ping başarılı."

Entegrasyonunuz hayırlı olsun! Sorularınız veya geliştirme talepleriniz her zaman değerlidir. İyi çalışmalar.
