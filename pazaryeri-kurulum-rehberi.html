Pazaryeri Kurulum Rehberi

Müşterinin pazaryeri panelinden alacağı bilgiler ve OzyConnect panelinde dolduracağı alanlar tek ekranda.

Kurulum bilgileri mağazaya özeldir
i

Sabit entegratör bilgilerimiz müşteriye ait değildir. Hepsiburada tarafında oziyweb_dev, PttAVM tarafında OzyConnect seçilir. Mağazaya özel gizli bilgiler müşteri panelinden alınır ve OzyConnect ayar ekranına girilir.

Entegratör sabit
  1. Hepsiburada Merchant Panel'e girin.
  2. Bilgilerim → Entegrasyon → Entegratör Bilgileri bölümüne gidin.
  3. Entegratör olarak oziyweb_dev kullanıcısına yetki verin.
  4. Servis Anahtarı butonundan servis anahtarını kopyalayın.
  5. Mağaza ID / Merchant ID bilgisini aynı ekrandan kopyalayın.

OzyConnect paneline girilecekler

  • Şifre / Servis Anahtarı
  • Merchant ID / Mağaza ID

Entegratör Kullanıcı Adı otomatik: oziyweb_dev

API Key sabit
  1. PttAVM satıcı paneline girin.
  2. Entegrasyon veya API ayarları bölümünde entegratör olarak OzyConnect seçin.
  3. Mağazanız için verilen Access Token bilgisini kopyalayın.
  4. Varsa Shop ID / Mağaza ID bilgisini not edin.

OzyConnect paneline girilecekler

  • Access Token
  • Shop ID / Mağaza ID, varsa

PttAVM API Key sistem tarafından otomatik kullanılır.

SP-API OAuth
  1. Amazon Seller Central'a ana hesap veya yetkili kullanıcıyla girin.
  2. Apps & Services → Develop Apps bölümünden SP-API uygulaması oluşturun veya mevcut uygulamayı açın.
  3. LWA credentials bölümünden Client ID ve Client Secret bilgilerini alın.
  4. Uygulamayı Amazon hesabınız için authorize ederek Refresh Token üretin.
  5. Seller Central hesap bilgilerinden Seller ID / Merchant Token bilgisini alın.

OzyConnect paneline girilecekler

  • LWA Client ID
  • LWA Client Secret
  • Refresh Token
  • Seller ID

Amazon TR marketplace ID sistemde sabittir: A33AVAJ2PDY3EV

Satıcı API
  1. Trendyol Satıcı Paneli'ne girin.
  2. Hesabım → Entegrasyon Bilgileri bölümünü açın.
  3. Satıcı ID / Supplier ID bilgisini kopyalayın.
  4. API Key ve API Secret bilgilerini kopyalayın.

OzyConnect paneline girilecekler

  • Supplier ID
  • API Key
  • API Secret
REST API
  1. n11 Mağaza Yönetim Paneli'ne girin.
  2. API / Entegrasyon ayarları bölümünü açın.
  3. Mağazaya ait API Key ve API Secret bilgilerini alın.

OzyConnect paneline girilecekler

  • API Key
  • API Secret
OAuth
  1. Pazarama İş Ortağım paneline girin.
  2. Entegrasyon / API bilgileri bölümünden uygulama bilgilerini açın.
  3. Client ID ve Client Secret bilgilerini kopyalayın.

OzyConnect paneline girilecekler

  • Client ID
  • Client Secret
API Anahtarı
  1. ÇiçekSepeti satıcı paneline girin.
  2. Entegrasyon veya API ayarları bölümünü açın.
  3. Mağazaya özel API Key bilgisini kopyalayın.

OzyConnect paneline girilecekler

  • API Key
Merchant API
  1. İdefix satıcı paneline girin.
  2. Entegrasyon veya API ayarları bölümünden mağaza bilgilerini açın.
  3. Vendor ID / Merchant ID bilgisini kopyalayın.
  4. API erişimi için verilen API Key bilgisini alın.

OzyConnect paneline girilecekler

  • Vendor ID / Merchant ID
  • API Key

Bu rehberdeki sabit entegratör adları OzyConnect'e aittir; servis anahtarı, token, merchant ID ve benzeri gizli bilgiler her mağaza için müşteri panelinden alınmalıdır.
