Lisanslama, doğrulama ve PHP kod koruma rehberi

OzyConnect Panel'in ticari dağıtımında kullanılacak lisans mimarisini, domain doğrulama akışını, IonCube şifreleme stratejisini ve üretim teslim kontrol listesini tek bir profesyonel dokümanda toplar.

Genel Bakış

Lisanslama sistemi; müşteriye verilen lisans anahtarını, kurulum yapılan domaini, ürün sürümünü ve izin verilen özellikleri doğrulayarak uygulamanın yalnızca yetkili ortamlarda çalışmasını sağlar.

01
Yetkili domain

Panel yalnızca lisansa tanımlı alan adı veya izinli alias üzerinde çalışır.

02
Merkezi doğrulama

Lisans durumu, süre ve paket özellikleri lisans sunucusundan alınır.

03
Kod koruma

Kritik PHP dosyaları IonCube ile okunamaz ve değiştirilemez hale getirilir.

Tavsiye edilen standart: Domain tabanlı lisans + imzalı doğrulama yanıtı + IonCube ile şifrelenmiş çekirdek dosyalar + çevrimdışı cache.

Domain Tabanlı Lisanslama

Varsayılan model olarak domain tabanlı lisanslama kullanılmalıdır. Müşteri satın alma veya kurulum sırasında domain bilgisini verir; sistem bu domaini lisans anahtarı ile birlikte doğrular.

Domain bilgisi alınır

HTTP_HOST normalize edilir; www, port ve protokol farkları temizlenir.

Lisans anahtarı okunur

.env veya güvenli yapılandırma dosyasındaki lisans anahtarı hazırlanır.

Sunucuya doğrulama isteği gönderilir

Domain, sürüm, kurulum kimliği ve zaman damgası imzalı istek olarak iletilir.

Yanıt imzası doğrulanır

Yanıtın gerçekten lisans sunucusundan geldiği public key veya shared secret ile kontrol edilir.

Sonuç cache'e alınır

Geçerli sonuç kısa süreli, çevrimdışı tolerans bilgisi ise ayrı ve şifreli olarak saklanır.

Önerilen yapılandırma

// config/license.php
return [
    'enabled' => env('LICENSE_ENABLED', true),
    'method' => env('LICENSE_METHOD', 'domain'),
    'domain' => env('LICENSE_DOMAIN', ''),
    'license_key' => env('LICENSE_KEY', ''),
    'server_url' => env('LICENSE_SERVER_URL', 'https://license.oziyweb.com/api/validate'),
    'cache_ttl' => 3600,
    'offline_grace_days' => 30,
    'public_key_path' => __DIR__ . '/../storage/license_public.key',
];

Not: Domain karşılaştırması yaparken example.com ve www.example.com için aynı lisansın geçerli olup olmayacağı lisans panelinde açıkça tanımlanmalıdır.

Lisans Anahtarı Formatı

Lisans anahtarı insan tarafından okunabilir olmalı; ancak güvenlik doğrulaması yalnızca anahtar formatına değil, sunucu taraflı kayıt ve imzalı yanıta dayanmalıdır. 

OZYC-ABCD-EFGH-IJKL-MNOP-QRST-UVWX-YZAB

OZYC  = Ürün prefix'i
ABCD  = Müşteri kodu
EFGH  = Ürün/paket kodu
IJKL  = Major sürüm bilgisi
MNOP  = Lisans tipi
QRST  = Oluşturma tarihi kodu
UVWX  = Rastgele güvenlik segmenti
YZAB  = Checksum

Yerelde tutulacak bilgiler

  • Lisans anahtarı
  • Aktif domain veya domain alias listesi
  • Son başarılı doğrulama tarihi
  • Offline grace bitiş tarihi
  • İzin verilen özellikler

Sunucuda tutulacak bilgiler

  • Müşteri ve sipariş kaydı
  • Lisans durumu: aktif, askıda, iptal, süresi doldu
  • Domain, IP ve kurulum kimliği
  • Paket özellikleri ve kota bilgileri
  • Son doğrulama kayıtları

Kod Koruma ve IonCube

Lisans kontrolü açık kaynak dosyalarda bırakılırsa kolayca devre dışı bırakılabilir. Bu nedenle kritik çalışma akışı IonCube ile korunan dosyalarda bulunmalıdır.

Öncelik Dosyalar Neden Önemli
Tier 1 public/index.php, app/Core/Router.php, app/Core/Container.php, installer.php Uygulama başlangıcı, yönlendirme ve kurulum akışı burada başlar.
Tier 2 app/Middleware/*, app/Controllers/AuthController.php, app/Controllers/ApiTokenController.php Kimlik doğrulama, API erişimi ve güvenlik kapıları bu katmandadır.
Tier 3 app/Models/*, servis sınıfları, entegrasyon yardımcıları İş kuralları, paket özellikleri ve lisans kısıtları burada uygulanabilir.

IonCube loader kurulumu

# Loader paketini indir
wget https://downloads.ioncube.com/loader_downloads/ioncube_loaders_lin_x86-64.tar.gz
tar xzf ioncube_loaders_lin_x86-64.tar.gz

# PHP extension dizinini öğren
php -i | grep extension_dir

# Uygun loader dosyasını extension dizinine taşı
sudo cp ioncube/ioncube_loader_lin_8.3.so /usr/lib/php/20230831/

# php.ini içine ekle
zend_extension = /usr/lib/php/20230831/ioncube_loader_lin_8.3.so

# Web sunucusunu yeniden başlat
sudo systemctl restart apache2

Örnek şifreleme komutu

# Domain kilitli paket üretimi
ioncube_encoder \
  --into encrypted-build \
  --replace-target \
  --allowed-server example.com,www.example.com \
  --expire-on 2026-12-31 \
  public/index.php app/Core app/Middleware installer.php

Güvenlik uyarısı: IonCube koruması lisans mimarisinin yerine geçmez. Lisans doğrulama, imzalı yanıt, cache bütünlüğü ve sunucu taraflı kayıt birlikte kullanılmalıdır.

Hata yanıtları

Kod Durum Anlamı Önerilen Davranış
license_expired 403 Lisans süresi dolmuştur. Paneli kısıtlı moda al, ödeme veya yenileme ekranı göster.
domain_mismatch 403 Mevcut domain lisansa kayıtlı değildir. Kurulumu durdur, destek iletişimi göster.
license_suspended 403 Lisans yönetici tarafından askıya alınmıştır. Çalışmayı engelle ve kayıt oluştur.
server_unreachable 503 Lisans sunucusuna ulaşılamıyor. Geçerli offline cache varsa çalışmaya devam et.

Uygulama Adımları

Lisans kontrolü tek bir dosyaya sıkıştırılmamalıdır. Başlangıçta doğrulama yapılmalı, kritik özelliklerde paket yetkileri tekrar kontrol edilmeli ve sonuçlar loglanmalıdır.

.env değişkenleri

LICENSE_ENABLED=true
LICENSE_METHOD=domain
LICENSE_DOMAIN=example.com
LICENSE_KEY=OZYC-ABCD-EFGH-IJKL-MNOP-QRST-UVWX-YZAB
LICENSE_SERVER_URL=https://license.oziyweb.com/api/license/validate

Başlangıç kontrolü

// public/index.php veya bootstrap aşaması
if (env('LICENSE_ENABLED', true) && PHP_SAPI !== 'cli') {
    try {
        $validator = new App\Services\LicenseValidator();
        $license = $validator->validateOrFail();

        app()->instance('license', $license);
    } catch (App\Exceptions\LicenseException $exception) {
        http_response_code(403);
        require __DIR__ . '/../views/errors/license.php';
        exit;
    }
}

Sık Sorulan Sorular

Domain değişirse lisans geçerli kalır mı?

Varsayılan olarak hayır. Domain değişiminde lisans panelinden yeni domain tanımlanmalı veya mevcut lisans yeniden aktive edilmelidir.

Lisans sunucusu geçici olarak kapalıysa panel çalışır mı?

Son başarılı doğrulama cache'i geçerliyse çalışabilir. Önerilen çevrimdışı tolerans 30 gündür; bu süre dolduğunda panel güvenli moda alınmalıdır.

Müşteri IonCube loader'ı kaldırırsa ne olur?

IonCube ile şifrelenmiş dosyalar çalışmaz. Bu nedenle lisans kontrolü ve kritik uygulama başlangıcı mutlaka şifreli dosyaların içinde bulunmalıdır.

Trial lisans nasıl verilir?

Lisans tipi trial olarak işaretlenir, expires_at alanı deneme bitiş tarihine ayarlanır ve gerekiyorsa özellik listesi kısıtlanır.

Lisans ne sıklıkla doğrulanmalıdır?

Başlangıçta mutlaka doğrulanmalı, sonrasında cache TTL doldukça yenilenmelidir. Hassas özelliklerde paket yetkisi ayrıca kontrol edilmelidir.

Teslim Notu

OzyConnect Panel lisanslama paketi hazır kabul kriteri: Lisans doğrulama aktif, kritik dosyalar korunmuş, doğru domain test edilmiş, offline fallback senaryosu denenmiş ve müşteri destek iletişim bilgisi hata ekranlarında görünür olmalıdır.
